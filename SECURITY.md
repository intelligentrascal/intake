# Security

## Reporting

Please report security issues privately to the maintainer via GitHub Security Advisories on this repository (preferred) or a private channel the maintainer publishes.

Do not file public issues for undisclosed vulnerabilities.

## Scope

Intake watches local folders and may move/rename files under user-configured paths. It should never send file contents to a network service unless the user explicitly enables an AI provider and a feature that requires it.
