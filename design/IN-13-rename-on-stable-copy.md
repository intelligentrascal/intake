# IN-13 · Rename on stable — Settings copy

**Product:** Intake · **Surface:** General → Organizing · **For:** Intake Dev

## Toggle

| | Copy |
|---|---|
| **Label** | `Rename when download finishes` |
| **Default** | On |
| **Footer** | `Renames the file as soon as the download is stable — on this Mac only. Wait before organizing still delays filing into folders.` |
| **Compact footer** (only if space is truly tight) | `Local rename when the file is ready. Wait only delays filing.` |

## Placement

Place in **Organizing** near **Automatic organizing** / **Wait before organizing**.

Keep the Wait footer: “New downloads stay in the folder until this time has passed, so you can open them before Intake files them.”

## Language

- Local, on this Mac only.
- Do **not** say “AI rename”, cloud, or OpenRouter on this control.
- Wait still delays **filing into folders**, not the rename.
