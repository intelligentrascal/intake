Rules

Not magic you trust.

Lazy folders. Intake never pre-creates an empty category. A folder appears the first time a file needs it — and not a day sooner.

Go beyond file type.

Rules can match where a file came from, what it's called, or how big it is. Combine them; the first match in your list wins. Source domains are read from local file metadata — Intake never makes a network request to resolve one.

Add year or month subfolders — Images/2026-09/photo.jpg — or keep it flat. The choice is per rule.

Control

See everything.
Change anything.

Intake never asks for blind trust. Every action is previewed before it happens, logged after it happens, and reversible with one click.

Tidy the files
already there.

Organize Existing… scans the root of your watch folders and shows you exactly what it would rename and where each file would go — grouped by destination, with new folders marked.

Nothing is touched until you click Organize. It's a one-shot you run when you choose, and it works even with Automatic organizing turned off.

Privacy

It works on files.
Not on you.

Intake is local-first. It touches your files and nothing else — and makes no network request unless you turn one on.

Local by default

Renames, rules, domain lookups and cleanup all run on your Mac. The default naming provider, On this Mac, sends file contents nowhere.

Asks at the right moment

OpenRouter is opt-in and off by default. Intake asks before file text leaves your Mac, and before it requests notification permission — never at launch.

No telemetry

No analytics, no tracking, no update-checks pinging home. Feedback is a prefilled GitHub issue you send yourself, only when you choose to.

Native citizen

At home on your Mac.

A real macOS app — not a website in a trench coat. It follows the platform, so it never fights it.

Dock & menu bar

Status, Pause, Organize Existing… and Activity, always one click away. Hide either one — but not both.

Notification digests

Batched summaries, never one alert per file. Off by default; permission is only requested when you turn it on.

Light & dark mode

System semantic colors throughout, so Intake looks correct next to every other window you have open.

Reduce Motion aware

Animations respect your accessibility settings, alongside Increase Contrast and Reduce Transparency.

Pause anything

Pause filing from the menu bar, per folder. Renaming keeps working — the two controls are independent.

Signed & notarized

Built with a Developer ID and notarized by Apple. Open the DMG, drag to Applications, done — no workarounds.

Questions

Good to know.

Why isn't Intake filing my downloads?
Files wait out Wait before organizing — two hours by default — before they're filed. If the menu bar shows Paused, or Automatic organizing is off, filing stops while renaming keeps going. A folder marked Needs access can be re-granted in Settings → General.
Can I get a file back where it was?
Yes. Open Activity and click Undo on the rename or the move. Your most recent twenty changes are undoable; older entries remain in Activity as history.
Will it reorganize files I already have?
Only when you ask. Organize Existing… never runs on its own, and it previews every rename and move before you commit. Files already sitting in category folders are always left alone.
Does it send my files anywhere?
No. Intake works on local files only. It makes a network request only if you enable OpenRouter for folder suggestions or content-aware names — both off by default — or if you choose Send Feedback…. The default naming provider runs entirely on your Mac.
What does it cost?
Intake is free and open source under the MIT license. Releases are signed with a Developer ID and notarized by Apple, with a SHA-256 checksum published for every download.
